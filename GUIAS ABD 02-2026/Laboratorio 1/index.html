¿Qué son las Window Functions?

Las Window Functions realizan cálculos sobre filas relacionadas con la fila actual, sin agrupar el resultado como lo hace GROUP BY. Así conservan el contexto de cada registro.

Ejemplo conceptual

Imagina que deseas calcular el promedio de ventas por región, pero mostrando todas las filas de vendedores. Con GROUP BY obtendrías una fila por región; con OVER(PARTITION BY ...) obtienes el promedio en cada fila sin perder el detalle.

Los temas de esta guía complementan lo aprendido sobre funciones de agregación, GROUP BY, HAVING y subconsultas.

Funciones ventana: úsalas cuando necesitas calcular un promedio, total, ranking o comparación por grupo, pero quieres seguir viendo cada fila. A diferencia de GROUP BY, no reducen el resultado a una fila por grupo.

CTE: úsalo cuando una consulta o subconsulta es difícil de leer. El CTE le da nombre a un resultado temporal y permite dividir la solución en pasos claros. No crea una tabla permanente.

PIVOT: úsalo cuando los datos están en filas, pero el reporte debe mostrar categorías, meses o años como columnas. UNPIVOT hace el proceso contrario.

En resumen: funciones ventana analizan sin perder filas; CTE organiza la consulta; PIVOT cambia la forma del resultado.

La función se escribe antes de OVER(). Dentro de OVER(), PARTITION BY crea grupos y ORDER BY define el orden interno.

Comando/FunciónDescripciónEjemplo
OVER()Indica que el cálculo se realizará como ventana.AVG(ListPrice) OVER()
PARTITION BYDivide las filas en grupos y reinicia el cálculo en cada grupo.AVG(ListPrice) OVER (PARTITION BY ProductSubcategoryID)
ORDER BYEstablece el orden para rankings, acumulados y comparaciones.RANK() OVER (ORDER BY ListPrice DESC)

Ejemplo:


SELECT ProductID, Name, ProductSubcategoryID, ListPrice,
       AVG(ListPrice) OVER (
           PARTITION BY ProductSubcategoryID
       ) AS promedio_subcategoria
FROM Production.Product
WHERE ListPrice > 0;
  • WHERE filtra antes del cálculo.
  • La partición forma una ventana por subcategoría.
  • No se usa GROUP BY, por lo que cada producto permanece visible.

Permiten mostrar estadísticas del grupo junto a cada fila. Son útiles para comparar un valor individual con el total, promedio o extremo de su categoría.

Comando/FunciónDescripciónEjemplo
SUM() OVER()Total por partición o total acumulado.SUM(TotalDue) OVER (PARTITION BY TerritoryID)
AVG() OVER()Promedio del grupo sin ocultar filas.AVG(ListPrice) OVER (PARTITION BY ProductSubcategoryID)
MIN()/MAX() OVER()Menor y mayor valor de la partición.MAX(ListPrice) OVER (PARTITION BY ProductSubcategoryID)
COUNT() OVER()Cantidad de filas en la partición.COUNT(*) OVER (PARTITION BY CustomerID)
 

SELECT Name, ListPrice,
       MIN(ListPrice) OVER (PARTITION BY ProductSubcategoryID) AS minimo,
       MAX(ListPrice) OVER (PARTITION BY ProductSubcategoryID) AS maximo
FROM Production.Product
WHERE ListPrice > 0;

Tip: si el cálculo debe reiniciarse por cliente, vendedor o territorio, cambia la columna de PARTITION BY.

Las funciones de ranking asignan posiciones según un orden. La diferencia principal está en cómo tratan los empates.

Comando/FunciónDescripciónEjemplo
ROW_NUMBER()Numera todas las filas; los empates reciben números diferentes.ROW_NUMBER() OVER (ORDER BY ListPrice DESC)
RANK()Los empates comparten puesto y el siguiente puesto deja un salto.RANK() OVER (ORDER BY ListPrice DESC)
DENSE_RANK()Los empates comparten puesto sin dejar saltos.DENSE_RANK() OVER (ORDER BY ListPrice DESC)
NTILE(4)Divide las filas ordenadas en cuatro grupos similares.NTILE(4) OVER (ORDER BY ListPrice)
PERCENT_RANK()Expresa la posición relativa entre 0 y 1.PERCENT_RANK() OVER (ORDER BY ListPrice)
 

SELECT Name, ProductSubcategoryID, ListPrice,
       RANK() OVER (
           PARTITION BY ProductSubcategoryID
           ORDER BY ListPrice DESC
       ) AS rango
FROM Production.Product
WHERE ListPrice > 0;

DESC coloca el mayor precio en el puesto 1. La partición hace que el ranking vuelva a comenzar en cada subcategoría.

Estas funciones comparan la fila actual con otras filas de la ventana. Los marcos determinan cuántas filas cercanas participan en un promedio o suma móvil.

Comando/FunciónDescripciónEjemplo
LAG()Devuelve el valor de la fila anterior.LAG(TotalDue) OVER (ORDER BY OrderDate)
LEAD()Devuelve el valor de la fila siguiente.LEAD(TotalDue) OVER (ORDER BY OrderDate)
FIRST_VALUE()/LAST_VALUE()Obtienen el primer o último valor del marco.FIRST_VALUE(TotalDue) OVER (ORDER BY OrderDate)
ROWS BETWEENDefine las filas usadas en un cálculo móvil.ROWS BETWEEN 2 PRECEDING AND CURRENT ROW
 

SELECT CustomerID, SalesOrderID, OrderDate, TotalDue,
       LAG(TotalDue) OVER (
           PARTITION BY CustomerID ORDER BY OrderDate, SalesOrderID
       ) AS pedido_anterior,
       AVG(TotalDue) OVER (
           PARTITION BY CustomerID ORDER BY OrderDate, SalesOrderID
           ROWS BETWEEN 2 PRECEDING AND CURRENT ROW
       ) AS promedio_movil
FROM Sales.SalesOrderHeader;

La primera fila de cada cliente devuelve NULL en LAG(). El promedio móvil usa el pedido actual y hasta dos anteriores.

CTE: organizar consultas

Un CTE es un resultado temporal con nombre. Ayuda a dividir una consulta compleja en pasos y existe únicamente durante la sentencia siguiente.

Comando/FunciónDescripciónEjemplo
WITH ... ASDeclara el resultado temporal.;WITH Productos AS (SELECT * FROM Production.Product)
CTE múltiplesSe separan por coma; uno puede usar el resultado anterior.WITH A AS (...), B AS (SELECT * FROM A)
CTE recursivaGenera secuencias o recorre jerarquías con UNION ALL.SELECT 1 UNION ALL SELECT n + 1 FROM N WHERE n < 5
MAXRECURSIONControla el límite de repeticiones.OPTION (MAXRECURSION 100)
 

;WITH ProductosConPrecio AS (
    SELECT ProductID, Name, ListPrice
    FROM Production.Product
    WHERE ListPrice > 0
)
SELECT * FROM ProductosConPrecio;

Línea clave: el SELECT final es la única sentencia que puede utilizar ese CTE.

PIVOT: transformar el reporte

PIVOT convierte valores de filas en columnas; UNPIVOT devuelve columnas a filas. La lista IN (...) debe conocerse antes de ejecutar un PIVOT normal.

Comando/FunciónDescripciónEjemplo
PIVOTCrea columnas y agrega sus valores.PIVOT (SUM(LineTotal) FOR Anio IN ([2011], [2012]))
FOR ... IN (...)Define la columna pivote y las columnas finales.FOR Anio IN ([2011], [2012], [2013], [2014])
UNPIVOTConvierte las columnas indicadas en filas.UNPIVOT (Monto FOR Anio IN ([2011], [2012]))
 

SELECT ProductID, [2011], [2012], [2013], [2014]
FROM (
  SELECT d.ProductID, YEAR(h.OrderDate) AS Anio, d.LineTotal
  FROM Sales.SalesOrderHeader h
  JOIN Sales.SalesOrderDetail d ON d.SalesOrderID = h.SalesOrderID
) fuente
PIVOT (SUM(LineTotal) FOR Anio IN ([2011], [2012], [2013], [2014])) p;

Líneas clave: YEAR(OrderDate) genera las categorías que se vuelven columnas y SUM(LineTotal) agrega los valores de cada producto y año.
TemaComandos principalesCuándo usarlo
Agregación ventanaSUM/AVG/MIN/MAX/COUNT OVEREstadísticas por grupo conservando cada fila.
RankingROW_NUMBER, RANK, DENSE_RANK, NTILENumerar, clasificar o dividir registros.
DesplazamientoLAG, LEAD, FIRST_VALUE, LAST_VALUEComparar filas anteriores, siguientes o de referencia.
MarcosROWS BETWEENPromedios móviles y sumas rodantes.
CTEWITH, CTE múltiples y recursivasOrganizar consultas en pasos o generar secuencias.
PIVOTPIVOT, UNPIVOT, FOR ... INConvertir filas en columnas y viceversa.
